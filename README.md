# 🚀 Personal Portfolio

A modern and dynamic personal portfolio built with the latest web technologies to showcase projects, skills, and professional experience.

## 🛠️ Tech Stack

This project is built with a modern stack focused on performance, accessibility, and user experience:

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Internationalization (i18n):** [Next-intl](https://next-intl-docs.vercel.app/)
- **Forms & Validation:** [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/)
- **Emails:** [Resend](https://resend.com/)
- **Toast Notifications:** [Sonner](https://sonner.emilkowal.ski/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **E2E Testing:** [Playwright](https://playwright.dev/)
- **Package Manager:** [pnpm](https://pnpm.io/)

## 📁 Project Structure

```text
src/
├── app/          # Application routes and pages (App Router)
├── components/   # Reusable UI components (buttons, cards, etc.)
├── constants/    # Static data (e.g., projects information)
├── hooks/        # Custom React hooks
├── i18n/         # Internationalization setup
└── messages/     # Translation dictionaries (en.json, es.json)
```

## 🌐 Internationalization

The portfolio supports multiple languages (English and Spanish) using `next-intl`. Translation dictionaries are located in the `src/messages/` folder. You can edit `en.json` or `es.json` to modify the application's text.

## ✉️ Contact Form

The contact form is client-side validated using **Zod** and **React Hook Form**. Emails are sent securely using **Resend**.

Este proyecto está construido con un stack moderno enfocado en rendimiento, accesibilidad y experiencia de usuario:

- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones:** [Framer Motion](https://www.framer.com/motion/)
- **Internacionalización (i18n):** [Next-intl](https://next-intl-docs.vercel.app/)
